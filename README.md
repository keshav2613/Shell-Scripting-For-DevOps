# Shell Scripting for DevOps 🐚

A collection of Bash automation scripts for common DevOps and cloud operations, including AWS infrastructure provisioning and application deployment.

## 🛠️ Technologies

`Bash` `Linux` `AWS CLI` `EC2` `Django` `Git` `DevOps Automation`

## 📜 Automation Scripts

| Script                 | Purpose                                                   |
| ---------------------- | --------------------------------------------------------- |
| `create_ec2.sh`        | Automates EC2-related infrastructure tasks using AWS CLI  |
| `deploy_django_app.sh` | Automates deployment steps for a Django application       |
| `error_handle.sh`      | Demonstrates error handling for reliable shell automation |
